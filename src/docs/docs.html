API Reference

Complete guide to integrating with our e-commerce platform API

Base URL: https://api.example.com

Authentication

POST /api/auth/register/send-otp
Optional

Sends a one-time password (OTP) to the user for registration.

Request Body

{
  "email": "user@example.com",
  "phone": "+1234567890"
}

Parameters

email string, required

The email address to send OTP to

phone string, required

The phone number to send OTP to

POST /api/auth/register/verify-otp
Optional

Verifies the OTP and completes the registration process.

Request Body

{
  "email": "user@example.com",
  "phone": "+1234567890",
  "otp": "123456",
  "password": "securePassword123"
}

Parameters

email string, required
phone string, required
otp string, required
password string, required
POST /api/auth/login
Optional

Logs in a user and returns a JWT token.

Request Body

{
  "email": "user@example.com",
  "password": "securePassword123"
}

Response

{
  "token": "jwt_token_here",
  "user": {
    "id": "user_id",
    "name": "User Name",
    "email": "user@example.com"
  }
}
GET /api/auth/me
Required

Gets the current user's profile information.

Authentication required: Bearer token in Authorization header 

{
  "id": "user_id",
  "name": "User Name",
  "email": "user@example.com",
  "created_at": "2023-01-01T00:00:00Z"
}

Products

GET /api/products
Optional

Gets all public products.

Query Parameters

limit integer

Maximum number of results (default: 20)

offset integer

Number of items to skip for pagination

search string

Search term to filter products

Response

{
  "products": [
    {
      "id": "product_id",
      "name": "Product Name",
      "price": 29.99,
      "currency": "USD",
      "image": "https://example.com/image.jpg",
      "description": "Product description"
    }
  ],
  "total": 50,
  "limit": 20,
  "offset": 0
}
GET /api/products/details/:id
Optional

Gets detailed product information by ID.

Path Parameters

id string, required

The product ID

Response

{
  "id": "product_id",
  "name": "Product Name",
  "description": "Detailed product description",
  "price": 29.99,
  "currency": "USD",
  "images": ["https://example.com/image1.jpg"],
  "attributes": [
    {
      "name": "Color",
      "value": "Blue"
    }
  ],
  "category": {
    "id": "category_id",
    "name": "Electronics"
  }
}

Required

Adds an item to the current user's cart.

Authentication required: Bearer token in Authorization header 

{
  "product_id": "product_id",
  "quantity": 1,
  "attributes": [
    {
      "name": "Color",
      "value": "Blue"
    }
  ]
}
PUT /api/cart/update
Required

Updates a cart item.

Authentication required: Bearer token in Authorization header 

{
  "item_id": "cart_item_id",
  "quantity": 3
}
DELETE /api/cart/remove/:itemId
Required

Removes an item from the cart.

Authentication required: Bearer token in Authorization header

Path Parameters

itemId string, required

The cart item ID

Response

Item removed successfully
